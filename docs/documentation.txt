#Main.java
main файл программы
содержит осноывные переменные:
  -- winWidth, winHeight - размеры окна
  -- cellSize            - размер одной клеточки на экране в пикселях
создает окно (frame)
в бесконечном цикле обновляет окно с задержкой в 5* мс
*можете сами выставить удобную задержку или вообще её убрать


#GridFrame.java
класс отрисовки окна
содержит методы:
  -- paint            - отрисовка таблицы в окне, обновление координат камеры
  -- dispatchKeyEvent - обработка нажатий клавиш на клавиатуре:
      W - сдвинуть камеру вверх
      A - сдвинуть камеру влево
      S - сдвинуть камеру вниз
      D - сдвинуть камеру вправо
      I - zoom-in
      O - zoom-out
      L - включить/выключить отображение отладочных структур


#Grid.java
класс самой таблицы
содержит методы:
  -- noisePoint       - высчитывание значение шумовой функции в данной точке
  -- randomPoint      - выдает случайный цвет для точки
  -- getColorForValue - соответствие между числами от 0 до 4 и цветами:
      0 - глубокий водоём
      1 - неглубокий водоём
      2 - песок или берег
      3 - негустой лес, трава
      4 - густой лес, высокие деревья
      5 - крыша домика
      239 - отладочный цвет
      240 - граница тайлов (отладочный цвет)
  -- setCam           - установить значения координат камеры
  -- setCellSize      - установить размер клеточки
  -- setLogFlag       - обновить значение флага отладки
  -- saveTile         - отрисовка и сохранение не отрисованного ранее тайла
  -- findCity         - нахождение места под город в новом тайле
  -- checkCityDist    - проверка расстояний между городами
  -- paint            - отрисовка каждой клеточки на экране


#ImprovedPerlinNoise.java
класс с реализацие шумовой функции Перлина (фрактальной шумовой функции)


#CityGen
класс генерации деревнь
содержит методы:
  -- distance         - расстояние между двумя клетками плоскости
  -- addSmallHouse    - добавить в деревню маленький дом
  -- addNormHouse     - добавить средний дом
  -- addSmallHouse    - добавить большое здание
  -- findHousesRand   - рандомное размещение домов
  -- findHouses       - размещение домов используя алгоритм Бридсона (быстрая выборка Пуассоновского диска)
  -- addCity          - создать деревню в тайле
